# PuP — тестовая сборка для браузера

Собрано командой Unity **Tools → PuP → Build → Web (iPhone test)** из репозитория PuP и скопировано сюда. Исходников здесь нет.

- Касания включаются сами на телефоне; на компьютере — `?touch=1` в адресе.
- Чёткость на телефоне: по умолчанию не больше 2 пикселей на точку, иначе `?dpr=1.5`.
